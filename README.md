# YAML + Git Practice Project

Fictional data-pipeline configuration for learning YAML, VS Code, Git, and GitHub.
No company data, credentials, real endpoints, or production settings are included.

Files:
- config/ingestor.yaml
- config/transformer.yaml
- config/dq.yaml
- catalog/source_catalog.yaml

Practice: edit a few values, save, inspect Source Control / git diff, then stage, commit, and push to your own practice repository. All values are illustrative.
